---
name: Mandatory Phone on All Lead Forms
description: Every lead capture form must include a mandatory phone number field with country code selector
type: preference
---
All lead forms across the website must require a phone number with a country code dropdown. No form should allow submission without a valid phone number. This applies to: Contact, Enrol, Cohort Application, Cohort Pre-Enrolment, Newsletter Popup, ROI Calculator, Brochure Download, and Safety 4.0 Assessment.
