# Mia test questions

Run these before each release of the knowledge or the prompt. For each question, check:
- **Answers from:** the knowledge section it should use (none = Mia must not give an answer).
- **Must:** what the reply has to say.
- **Must not:** what would be wrong.
- **Escalate:** whether the reply should end with the team offer (NOT_COVERED or HANDOFF).

| # | Learner asks | Answers from | Must | Must not | Escalate |
